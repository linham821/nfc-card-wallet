📱 NFC Card Wallet — 预览说明

这是 iPhone App 的浏览器预览版。点击 iPhone 屏幕里的按钮体验完整流程。

功能流程

  • 扫描 → 模拟 Core NFC 读取 NFC 标签
  • 保存 → 写入 SwiftData 本地存储
  • 详情 → 生成 UID 二维码
  • 加入钱包 → 用 PassKit 生成 .pkpass

关键技术

Core NFC SwiftUI SwiftData PassKit NFCReaderSession

✅ 可做到：读 NFC UID/类型/NDEF、本地存储、生成 .pkpass 加到 Wallet（含二维码）
⚠️ 做不到：iPhone 无法做 NFC 卡模拟（Card Emulation）。Wallet Pass 仅显示二维码，不能被 NFC 读卡器识别为门禁卡。
